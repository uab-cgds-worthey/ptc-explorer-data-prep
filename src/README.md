# Order of scripts

Scripts to be ran in following order to prepare data set for the ptc-explorer app:

0. Run "init.R"
1. Run "prepare_metadata.R"
2. Run "prepare_variant_data.R"
3. Run "oncoplot_prepare_data.R"
4. Run "oncoplot_alt_fun.R" (optional)
5. Run "oncoplot_gene_exp_boxplots.R"
6. Run "oncoplot_main.R"
7. Run "enrichment_analysis_enrichR.R"
8. Run "prepare_fusion_deg_tbl.R"
9. Run "global_gene_aggregation.R"
10. Run "pack_data_for_ptc_explorer.R"
